# AI-Assisted Engineering - Usage Reflection

## 1. Introduction

I used ChatGPT as an AI-assisted engineering partner throughout the Streamhub QA Automation Assessment. The objective was to improve development productivity while understanding and validating the generated solutions.

## 2. How I Used AI

I used AI assistance for:

- Understanding the assessment requirements and planning the project structure.
- Developing the Playwright automation framework using TypeScript.
- Organising feature files, step definitions, and Page Object Model files.
- Understanding Playwright and Cucumber integration.
- Developing API test scenarios and validating response structures.
- Designing SQL schemas and writing queries for both assessment scenarios.
- Debugging SQL errors and validating query outputs.
- Improving project documentation and README instructions.

## 3. What Worked Well

- AI helped break down complex requirements into manageable tasks.
- It provided useful examples of Playwright locators and automation patterns.
- It helped develop SQL queries involving joins, date comparisons, and window functions.
- It helped identify potential implementation issues and suggest improvements.
- It accelerated documentation and debugging activities.

## 4. Challenges and Limitations

AI-generated suggestions were not always guaranteed to be correct.

Some challenges included:

- Understanding the actual DOM structure before selecting locators.
- Reviewing SQL logic to ensure the results matched the expected scenarios.
- Correcting suggestions that did not match the application or environment.
- Verifying generated code through actual execution rather than relying on AI explanations.

## 5. Human Validation and Engineering Judgement

I treated AI as an assistant rather than relying on it as the final decision-maker.

I reviewed the SQL queries, executed them using PostgreSQL in DB Fiddle, and compared the results with the expected outputs.

I also used actual test execution and error messages to guide debugging and validation.

## 6. Key Learnings

This assessment helped me understand how AI can improve QA engineering productivity when combined with technical knowledge and manual validation.

My main takeaway is that AI can accelerate development, but the responsibility for correctness, maintainability, and test reliability remains with the engineer.

## 7. Conclusion

Using AI as a pair-programming assistant helped me approach the assessment more efficiently. It also reinforced the importance of reviewing generated code, understanding the underlying logic, and validating every important change through execution.
